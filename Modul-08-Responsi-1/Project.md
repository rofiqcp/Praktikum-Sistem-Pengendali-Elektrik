# Checkpoint Project 08 — Board Siap Semester Lanjut

Sebelum masuk inverter/BLDC, setiap kelompok harus menunjukkan:
- PCB Rev.E assembled,
- power rail lulus,
- boot shutdown lulus,
- dead-time terukur,
- IA/IB/IDC zero-offset terkalibrasi,
- VBUS sesuai multimeter,
- Hall/Encoder terbaca,
- motor DC P5 berhasil dua arah.

Kelompok yang belum lulus checkpoint memperbaiki PCB sebelum P9.
