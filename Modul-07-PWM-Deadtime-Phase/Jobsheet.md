# Jobsheet 07 — Sweep Dead-Time dan Phase

Tanpa motor terlebih dahulu:
1. set carrier 8 kHz, dead-time 1500 ns;
2. ukur CH1/CH1N pada gate driver;
3. catat dead-time aktual dari osiloskop;
4. ulangi 1000, 1500, 2000 ns;
5. ulangi carrier 8, 12, 16, 20 kHz;
6. jalankan 3-phase sine dan ukur jarak phase A-B-C;
7. ubah spacing 120° menjadi 90° dan 150° hanya untuk melihat konsekuensi bentuk gelombang, bukan untuk motor normal.

Setelah waveform aman, motor boleh dipasang pada tegangan rendah untuk membandingkan suara/ripple.
