# Jobsheet 03 — Karakterisasi 4–20 mA

1. Pastikan VFD STOP.
2. Verifikasi terminal analog input current dan common.
3. Set source frequency = current input.
4. Set 4 mA = frekuensi minimum dan 20 mA = frekuensi maksimum yang diizinkan dosen.
5. Berikan 4, 8, 12, 16, 20 mA.
6. Untuk setiap titik catat arus terukur, frequency reference teoritis, display reference, output frequency, dan error.
7. Plot `I_mA` vs `F_Hz`.
8. Uji kondisi di bawah 4 mA sebagai simulasi loop abnormal tanpa menjalankan motor pada kondisi berbahaya.

### Analisis
Hitung slope, offset, maksimum error, dan kemungkinan sumber error (resolusi AO, kalibrasi meter, setting VFD, noise).
