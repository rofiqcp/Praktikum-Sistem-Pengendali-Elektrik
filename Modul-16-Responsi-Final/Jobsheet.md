# Jobsheet 16 — Responsi Final

Setiap mahasiswa/kelompok mendapat:
1. 5 pertanyaan konsep acak P1–P15,
2. 1 perhitungan (4–20 mA / timer PWM / electrical angle / Clarke-Park),
3. 1 troubleshooting scenario,
4. 1 demonstrasi hardware.

Demonstrasi dapat berupa VFD Modbus, DC H-bridge, six-step Hall, sensor calibration, atau FOC speed/position. Untuk demo FOC wajib menunjukkan startup shutdown, current calibration, angle sensor dan emergency stop software.
