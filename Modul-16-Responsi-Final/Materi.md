# Modul 16 — Responsi Final Sistem Pengendali Elektrik

Mahasiswa harus dapat menjelaskan sistem dari level industri hingga algoritma motor control dan membuktikannya pada hardware.

## Rantai kompetensi
PLC/VFD digital → 4–20 mA → RS485 → DC H-bridge → complementary PWM/dead-time → inverter 1-fasa → Hall six-step → sine PWM → SVPWM → sensing → Clarke/Park → current FOC → speed/position FOC.

## Fokus penilaian
- pemahaman sebab-akibat,
- keselamatan,
- kemampuan membaca waveform/data,
- debugging terstruktur,
- kemampuan menjelaskan hubungan hardware dan firmware.
